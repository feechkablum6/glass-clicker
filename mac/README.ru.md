# Кликер

Автокликер для macOS со стеклянным окном и плашкой поверх игр.
Одна горячая клавиша, скорость до 100 кликов в секунду, счёт кликов на виду.

</div>

Версия для Mac того же кликера, что и [glass-clicker](https://github.com/feechkablum6/glass-clicker) для Windows: те же окна, та же плашка, те же настройки. Отличается только слой, которым кликер разговаривает с системой.

## Плашка поверх всех окон

Кликер включают, не сворачивая игру, поэтому он сам сообщает о себе сверху по центру экрана. Плашка не перехватывает мышь и не забирает фокус: клики проходят сквозь неё. Карточка называет скорость и кнопку, через полторы секунды стягивается в пилюлю и считает клики вживую, а на выключении разворачивается с итогом захода и уходит.

## Окно

Стекло — системный материал macOS плюс собственный слой поверх него, поэтому надписи остаются читаемыми на любом фоне. Окно без рамки, таскается за шапку, скругление и тень рисует система.

## Русский и английский

При первом запуске кликер спрашивает язык и запоминает ответ. Переключается всё сразу: окно, плашка поверх игры, меню в строке меню и названия клавиш. Кнопка `RU` / `EN` в шапке окна меняет язык в любой момент, даже пока кликер работает.

## Что умеет

- Горячая клавиша по умолчанию — правый `Command`: нажали, кликер пошёл, нажали снова, остановился.
- Режим удержания: кликает, только пока клавиша зажата. Зажатый `Command` или `Shift` в клики не попадает, они уходят чистыми.
- Скорость от 1 до 100 кликов в секунду, ползунком, прямо во время работы.
- Клик левой или правой кнопкой.
- Любая клавиша или кнопка мыши на роль горячей, включая боковые кнопки игровых мышей.
- Escape останавливает кликер из любого приложения.
- Закрытие окна прячет кликер в строку меню, горячая клавиша продолжает работать.
- Счётчик кликов и настройки сохраняются между запусками.

## Разрешение системы

macOS не пропускает клики от приложения, пока оно не отмечено в разделе «Конфиденциальность и безопасность» → «Универсальный доступ». Пока разрешения нет, кликер не запускается и показывает окно с кнопкой, которая открывает нужный раздел настроек.

Сборка не подписана сертификатом разработчика, поэтому после каждой переустановки система считает приложение новым и просит выдать разрешение заново: снимите галочку с «Glass Clicker» и поставьте её снова.

## Установка из исходников

Нужны macOS 12 или новее, Apple Silicon и Node.js 20+.

```bash
npm install
npm run release
```

`npm run release` собирает приложение и кладёт его в «Программы», заменяя прежнюю версию.

Запуск из исходников, без установки:

```bash
npm start
```

Сборка `.dmg` для раздачи:

```bash
npm run build
```

## Как устроено

- Electron 43 — два окна: настройки и плашка поверх всех окон (без рамки, прозрачная, сквозная для мыши).
- [koffi](https://github.com/Koromix/koffi) — прямые вызовы CoreGraphics: `CGEventPost` для кликов, `CGEventSourceKeyState` и `CGEventSourceButtonState` для горячей клавиши.
- Расписание кликов держит заданный темп и не «догоняет» пропущенное после подвисания системы, поэтому залпа кликов не бывает.
- Логика вынесена из Electron в `lib/`, поэтому покрыта обычными тестами.

```bash
npm test
```
